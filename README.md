# github-proflie-analyzer 🚀

This is a web app that analyzes GitHub profiles and provides useful insights like top repositories and language usage.

## 🔥 Features
- Search any GitHub user
- View profile details (followers, repos, bio)
- Top 5 repositories based on stars
- Language usage visualization (chart)
- Clean and responsive UI

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript
- GitHub REST API
- Chart.js

## 🚀 Live Demo
https://codescope-parth.netlify.app/


## 📂 Installation & Usage
Clone the repository
Open index.html in your browser
